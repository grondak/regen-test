# Stage: Queue

Build a simple producer-consumer workflow using an in-memory queue.

Requirements:
- Use a file named `app.py`.
- Create a small `QueueWorker` that processes messages from `queue.Queue`.
- Put at least one message into the queue and process it.
- Print the processed value.
- Include a test that verifies the queue processing works.

This stage models asynchronous handoff through a queue.
