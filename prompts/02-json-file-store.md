# Stage: JSON file store

Create a small Python program that writes a JSON payload to disk and then reads it back.

Requirements:
- Use a file named `app.py`.
- Store a dictionary with at least `id`, `name`, and `status` keys in JSON form.
- Write the data to `data.json`.
- Read the file back and print the parsed JSON in a readable way.
- Include a test that verifies round-tripping the JSON file works.

This stage teaches the simplest durable state representation.
