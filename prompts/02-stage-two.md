# Stage: Stage Two

Create a tiny Python utility that prints a greeting for a supplied name.

Requirements:
- Use a single module named `app.py`.
- Provide a `main()` function that accepts an optional command-line argument.
- If no argument is passed, default to `World`.
- The output should be `Hello, World!` when no name is supplied.
- Include a small `test_app.py` that verifies the default greeting and a custom greeting.
- Keep the implementation clear and easy to study.

This stage illustrates a small extension beyond the foundation stage.
