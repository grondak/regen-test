# Prompt: Hello, World

Build a small Python command-line application that prints `Hello, World!` to standard output when run as a script.

Requirements:
- Use a single file named `app.py`.
- Add a `main()` function that prints the message.
- Use a guard so the app runs when executed directly.
- Include a corresponding test file named `test_app.py`.
- The test should verify that calling `main()` writes `Hello, World!` to stdout.
- Keep the implementation minimal and readable.

The generated app should be easy to regenerate from this prompt alone.
