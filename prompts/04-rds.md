# Stage: RDS

Build a small Python service that uses a managed relational database in a cloud environment.

Requirements:
- Use a file named `app.py`.
- Define a `StudentRepository` type with a method to save and load a student record.
- Use environment variables for database credentials such as `DB_HOST`, `DB_USER`, `DB_PASSWORD`, and `DB_NAME`.
- Keep the code readable so students can see the configuration boundary.
- Include a unit test that verifies the repository logic using a mock or placeholder configuration.

This stage models the move from local Linux storage to a managed database service.
