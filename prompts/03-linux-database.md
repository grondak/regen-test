# Stage: Linux database

Build a small Python application that stores rows in a SQLite database on a Linux filesystem.

Requirements:
- Use a file named `app.py`.
- Create a `students` table with `id` and `name` columns.
- Insert at least one row.
- Query the row back and print it.
- Include a test that verifies the row can be stored and retrieved.

This stage introduces a real local database as the persistence layer.
