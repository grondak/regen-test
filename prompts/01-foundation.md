# Stage: Foundation

Build a tiny Python command-line application that prints `Hello, World!` to standard output.

The generated project should remain intentionally minimal and easy to understand.

Requirements:
- Use a single file named `app.py`.
- Add a `main()` function.
- Print `Hello, World!` exactly once.
- Include a test named `test_app.py` that asserts stdout from `main()` equals `Hello, World!\n`.
- Include a `requirements.txt` file for the Python runtime.

This stage establishes the basic scaffold for later stages.
